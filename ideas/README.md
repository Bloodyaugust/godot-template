# ideas/

Markdown design notes for in-flight features. One file per idea. Move completed ideas into `done/` to keep the active set focused.

Mark any detail the agent filled in that the human hasn't decided with **(proposed)**, so the human can accept or change each one. A settled design folds into its `design/` doc; a build-plan note then carries the build order. When an idea ships, add the archive stamp right under its heading and move it into `done/` — see `done/_template.md` for both note shapes, the stamp and the markers.
