# ideas/done/

Archived design notes for shipped features. Kept for historical context.

See `_template.md` for the recommended shapes (a design note: Goal / Relationship To / Approach / Settled Decisions / Later Questions; a build-plan note: Relationship to / Approach / Steps / Out of scope / Human verification once built / Later questions), the italic archive stamp every archived note opens with, and the **(proposed)** marker convention. Copy and rename when archiving a shipped idea.
